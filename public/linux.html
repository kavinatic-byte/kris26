📖 Commands

  • ls
    Type ls and press Enter. It shows you what files and folders are in your current location — like opening a folder in File Explorer to see what's inside. Try it right now!
    $ ls
  • cd <folder>
    cd stands for "change directory". It moves you into a different folder. Type cd, a space, then the folder name. To go back up one level, type cd .. (two dots).
    $ cd myfolder
  • cat <file>
    cat dumps the entire contents of a file onto the screen all at once. Useful for short files, but for long files it will flood your terminal — you'll want to use head or tail instead.
    $ cat notes.txt
  • head <file>
    head shows you only the beginning (the "head") of a file — just the first few lines. Handy when a file is too long for cat and you only care about how it starts.
    $ head data.log
  • tail <file>
    tail is the opposite of head — it shows you the last few lines at the end of a file. Perfect for checking what was most recently added to a log.
    $ tail access.log
  • grep <word> <file>
    grep searches through a file and prints every line that contains the word or phrase you give it. Think of it as Ctrl+F for the terminal — great for finding one needle in a haystack.
    $ grep error app.log
